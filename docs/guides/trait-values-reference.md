# Legendary Trait Values & Familiar Reference

Every Legendary (Orange) trait scales as you bond more familiars carrying the same trait across **distinct species**. This page lists the exact stack values for every trait and which species can carry each one — use it as a planning reference when building a stack.

> [!TIP]
> For the rules on how trait stacking works, priority order (Yellow > Purple > Orange), and popular meta setups, see [Traits Stacking & Priorities](/guides/traits-guide).

## 4. How to Plan a Stack

1. **Pick your target trait** based on your build (e.g. MAIM for PvE crit, PRESCIENCE for PvP survivability).
2. **Check section 3** for the compatible species pool and achievable max.
3. **Bond one distinct species per stack** — duplicates of the same species do NOT count toward the stack.
4. **Verify each donor** hits the trait activation attribute threshold (**Primary/Secondary Attribute ≥ 170**) before bonding.
5. **Watch trait priority** — remember Yellow traits overwrite Orange in the 4-slot cap. See the [Priorities guide](/guides/traits-guide) for details.
