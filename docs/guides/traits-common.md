# Common traits
Also known as rare traits or yellow traits.
Multiple common traits on multiple different bonded familiars do not stack, only one common trait is used. For example, 4 different bonded familiars with common Maim each still grant only 1% Crit Chance total.

## Traits and Available Species
8 common traits are available:
| Trait | Compatible Species | Value |
| --- | --- | :---: |
| **MAIM** | Varog, Quakestrider, Broodtalon, Duskprowler | 1% |
| **DECIMATE** | Skitterwight, Stormlost, Broodtalon, Ashsweeper | 1.5% |
| **BESTIAL MIGHT** | Varog, Quakestrider, Broodtalon, Duskprowler, Bramblestalker | 1.5% |
| **FINESSE** | Stormlost, Quakestrider, Myrrjen, Ashsweeper, Bramblestalker | 1% |
| **FIENDISH HASTE** | Skitterwight, Stormlost, Quakestrider, Duskprowler | 1% |
| **SURVIVAL INSTINCT** | Skitterwight, Myrrjen, Ashsweeper, Duskprowler | 1% |
| **PRESCIENCE** | Varog, Myrrjen, Broodtalon, Ashsweeper, Bramblestalker | 1% |
| **STEADFAST** | Varog, Skitterwight, Stormlost, Myrrjen, Bramblestalker | 0.5% |


## Primary attributes for traits
Common traits require either primary or secondary attribute with the value 120 to activate.
But any common trait can be activated by any rare familiar attributes - rare familiars always have both 120+ primary and secondary attributes.

## Recommendation
The beginner advice is to find 4 rare familiars with all 8 common traits and send them to 4 bonded slots. Ideally if some of them have both common traits and utility traits.
Even though each trait value is low - 8 traits together give an equivalent of affixes of a good item.
